# Ben 10 Desktop Pet

A simple Windows desktop pet prototype inspired by Ben 10.

## Features
- Transparent always-on-top desktop window
- Ben-style vector character
- Omnitrix glow transformation effect
- Heatblast-style transformation state
- Double-click or press **Space** to transform
- Right-click to exit
- Drag the pet with the mouse

## Run

```bash
python main.py
```

No external packages are required; it uses Python's built-in Tkinter.

## Controls
- Double-click: transform
- Space: transform
- Left-click + drag: move window
- Right-click: exit

This is an original prototype using simple vector artwork, not official Ben 10 assets.
